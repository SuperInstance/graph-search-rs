# graph-search-rs

Graph algorithms in pure Rust.

## Algorithms

- **BFS** (breadth-first search)
- **DFS** (depth-first search)
- **Dijkstra** (shortest paths, non-negative weights)
- **Bellman-Ford** (shortest paths, detects negative cycles)
- **A*** (heuristic shortest path)
- **Topological Sort** (Kahn's algorithm)
- **Tarjan's SCC** (strongly connected components)
